# 🎮 Mini Arcade — 9 AI Battle Games

9개의 바닐라 자바스크립트 미니게임 아케이드. 모든 게임은 **🤖 AI vs 🧑 나** 대결 구조이며, 상대 AI의 연산력을 **실제 제품**에 빗대어 고를 수 있습니다.

**🍲 전자레인지 → 📱 피처폰 → 📺 스마트 TV → 📱 옴니아 → 📱 아이폰 3GS → 🧠 M4 Max**

전자레인지 상대의 2048에서 웃고, M4 Max 상대의 반응속도 대결에서 인간의 한계를 체감하세요.

## 실행 방법

### 리더보드(DB) 포함 — 권장

```bash
python3 server.py          # 표준 라이브러리만 사용 (설치 불필요)
# → http://127.0.0.1:8137/
```

게임 결과가 SQLite(`arcade.db`)에 기록되고 `leaderboard.html`에서 게임별 랭킹·최근 대국·통계를 볼 수 있습니다 (8초 자동 갱신).

- `POST /api/score` — 대국 결과 기록 `{game, player, cpu, result, score}`
- `GET /api/leaderboard` — 기록 조회 (`?game=` 필터)
- `GET /api/stats` — 총 대국/승리/플레이어 수

### DB 없이 정적 파일만

```bash
python3 -m http.server 8137   # 또는 index.html을 브라우저로 열기
```

게임은 정상 작동하지만 리더보드에 "DB 서버에 연결할 수 없습니다" 안내가 표시됩니다.

`index.html`이 로비입니다. 각 게임 하단의 "← 게임 로비로"로 복귀, "🏆 리더보드"로 기록 확인이 가능합니다.

## 기술 특징

- **제로 의존성**: 프레임워크·빌드 없는 vanilla JS 단일 파일들
- **게임별 맞춤 AI**: 미니맥스/알파베타(사목·오셀로·틱택토), expectimax 휴리스틱(2048), 패턴 빈도 예측(가위바위보), FIFO 메모리 모델(짝맞추기), 후보 소거법(숫자야구)
- **제품별 연산력 티어**: 6개 등급이 게임마다 속도·기억력·탐색 깊이 등 다른 축으로 작동
