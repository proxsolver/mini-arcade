📖 게임 설명서 — 9개 미니게임

모든 게임은 🤖 AI vs 🧑 나 대결 · 상대 등급은 제품별 연산력: 🍲 전자레인지 → 📱 피처폰 → 📺 스마트TV → 📱 옴니아 → 📱 아이폰3GS → 🧠 M4 Max

🔢2048 대결

같은 시드의 좌우 보드에서 먼저 2048을 만들거나 AI가 게임오버되면 승리. 방향키 조작, 첫 수부터 대결 시작. 등급 효과: 전자레인지(무작위·2초/수) → … → M4 Max(2수 전망·0.12초/수)

🔴사목 Connect Four

7×6 판에 돌을 떨어뜨려 가로·세로·대각선 4개 연결. 열 클릭·숫자키 1~7. 당신(노랑) 선공, 승리 라인 하이라이트. 등급 효과: 미니맥스 탐색 깊이 0(무작위) → 8수 앞까지 계산

⚪오셀로 리버시

끼워 잡아 뒤집고 돌이 많은 쪽이 승리. 파란 점이 둘 수 있는 곳, 패스 자동 처리. 등급 효과: 탐색 깊이 0~5 · Pentium급 이상은 코너를 내주지 않음

💾짝맞추기 메모리

같은 그림 2장을 뒤집어 짝을 더 많이 가져간 쪽이 승리. 짝 성공 시 한 번 더. 당신이 뒤집은 카드도 AI가 봄("기억 중 N장" 표시). 등급 효과: AI 기억력 0장(전자레인지) → 16장 전량(M4 Max·완벽 기억)

⭕틱택토

3×3에서 3칸 먼저 연결. 당신(X) 선공. M4 Max는 완벽 방어로 절대 지지 않음(최선 무승부). 등급 효과: 최적수를 둘 확률 10% → 100%

✌️가위바위보 심리전

5승 먼저. AI는 당신의 최근 패턴 빈도를 분석해 다음 수를 예측·카운터. 매 판 AI의 예측이 공개됨. 등급 효과: 예측 신뢰도 0%(완전 랜덤) → 80%(습관을 거의 다 읽음)

⚡반응속도 대결

빨간 불 후 초록 불에 클릭, 빠른 쪽이 1점 · 5점 먼저. 성급한 클릭은 치트로 실격. 인간 평균 약 250ms. 등급 효과: AI 반응 900ms(전자레인지) → 90ms(M4 Max·인간 한계 돌파)

🔨두더지잡기

20초간 같은 두더지를 잡아 점수 경쟁. 두더지는 0.9초 등장, 누가 잡았는지 라벨로 표시. 등급 효과: 명중률 25% → 97%, 반응 900ms → 180ms

⚾숫자야구

각자 3자리 비밀번호(중복 없음)를 정하고 교대로 추측. S=자리까지 정답, B=숫자만 정답. 적은 시도로 먼저 맞추면 승리. 등급 효과: 피드백 무시(전자레인지) → S만 기억 → 완전 소거법 → 정보 이득 극대화(M4 Max)
