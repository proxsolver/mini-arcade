📖 게임 설명서

9게임 전부 🤖 기계 vs 🧑 나. 상대 연산력: 🍲 전자레인지 → 📱 피처폰 → 📺 스마트TV → 📱 옴니아 → 📱 아이폰3GS → 🧠 M4 Max

🔢 2048 대결

같은 시드의 좌우 보드에서 먼저 2048 또는 상대 게임오버가 승리. 방향키 조작, 첫 수부터 대결 시작. 등급 효과: 전자레인지(무작위·2초/수) → M4 Max(2수 전망·0.12초/수)

🔴 사목 Connect Four

가로·세로·대각선 4개 연결. 열 클릭·숫자키 1~7. 당신 선공, 승리 라인 하이라이트. 등급 효과: 미니맥스 탐색 깊이 0 → 8수 앞까지 계산

⚪ 오셀로 리버시

끼워 잡아 뒤집고 돌이 많은 쪽이 승리. 파란 점 = 둘 수 있는 곳, 패스 자동. 등급 효과: 탐색 깊이 0~5 · 상위 등급은 코너를 내주지 않음

💾 짝맞추기 메모리

같은 그림 2장을 뒤집어 짝을 더 많이. 당신이 뒤집은 카드도 기계는 본다("기억 중 N장" 실시간 표시). 등급 효과: 기계의 기억력 0장 → 16장 전량

⭕ 틱택토

3칸 먼저 연결. 당신(X) 선공. 등급 효과: 최적수 확률 10% → 100%. M4 Max는 절대 지지 않음

✌️ 가위바위보 심리전

5승 먼저. 기계가 당신의 패턴 빈도를 분석해 카운터. 매 판 예측 공개. 등급 효과: 예측 신뢰도 0% → 80%

⚡ 반응속도 대결

초록 불에 클릭, 빠른 쪽 득점 · 5점 먼저. 성급한 클릭은 치트 실격. 등급 효과: 기계 반응 900ms → 90ms (인간 한계는 약 250ms)

🔨 두더지잡기

20초 점수 경쟁. 두더지는 0.9초 등장. 등급 효과: 명중률 25% → 97%, 반응 900ms → 180ms

⚾ 숫자야구

각자 3자리 비밀번호(중복 없음) 설정 후 교대 추측. S=자리 정답, B=숫자만 정답. 등급 효과: 힌트 무시 → 완전 소거법 + 정보이득 극대화

🧱 MiniCraft (혼자 놀이)

3D 블록 샌드박스. WASD 이동·점프, 좌클릭 파괴·우클릭 설치, F로 날기 모드. 잔디부터 금블록까지 8종. AI 대결 아님 — 자유롭게 짓고 부수는 크리에이티브 모드
